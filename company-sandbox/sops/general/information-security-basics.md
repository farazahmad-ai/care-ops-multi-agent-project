# CareOps Ltd: Information Security Basics

1. User passwords must meet complexity standards and never be shared between staff members.
2. Direct access to relational database infrastructure is strictly prohibited for non-infrastructure staff.
3. Access to staff HR and payroll modules is governed by role-based permissions outside user discretion.
